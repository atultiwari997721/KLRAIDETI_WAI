Quickstart Guide

Get up and running with KritiAI on Windows in less than two minutes.

Step 1: Download & Run Installer

Click the Download for Windows button to save KritiAi-desktop-win-x64.exe. Double click the installer to automatically set up the application, desktop shortcut, and Start menu launcher.

Step 2: Launch Workspace

Open KritiAI from your Desktop shortcut or run kritiai in your terminal from inside any repository directory. KritiAI will automatically index your codebase.

Step 3: Pair Program with AI

Give instructions in plain language. KritiAI will inspect files, propose diffs, run tests, and refine code alongside you with zero latency.
